## Production Checklist

### Pre-Recording
- [ ] Prepare demo account (or use test account)
- [ ] Have sample resume/context file ready
- [ ] Have real job posting URL ready
- [ ] Test all features work smoothly
- [ ] Clear browser cache for clean UI
- [ ] Close unnecessary tabs/apps
- [ ] Set browser zoom to 100%
- [ ] Test microphone audio levels
- [ ] Record in quiet environment

### During Recording
- [ ] Speak clearly and at moderate pace
- [ ] Pause briefly between sections
- [ ] Move cursor smoothly (not jerky)
- [ ] Don't rush through features
- [ ] Highlight important elements
- [ ] Keep consistent screen resolution

### Post-Recording
- [ ] Trim unnecessary pauses
- [ ] Add intro/outro graphics
- [ ] Add text overlays for key features
- [ ] Add background music (subtle)
- [ ] Add captions/subtitles
- [ ] Color correction
- [ ] Audio leveling
- [ ] Export in 1080p minimum
- [ ] Create thumbnail

## Pro Tips

1. **Record in sections**: Don't try to do it all in one take. Record each scene separately, then edit together.

2. **Use keyboard shortcuts**: Show them (e.g., Ctrl/Cmd+V for paste) - it looks more professional.

3. **Add zoom effects**: In post-production, zoom in on important UI elements for emphasis.

4. **Smooth transitions**: Use fade transitions between major sections.

5. **Highlight cursor**: Enable cursor highlighting in your recording software.

6. **Practice first**: Do a dry run without recording to get the flow smooth.

7. **Multiple takes**: Don't be afraid to re-record sections that don't look good.
