# Automated Video Creation Tools - Complete Guide

## Tools That Convert Markdown to Video (Automated)

### ✅ **Narakeet** (Recommended for Presentations)
- **What it does**: Converts Markdown scripts into videos with voiceover, images, and animations
- **How it works**: Upload Markdown file → AI generates video automatically
- **Best for**: Presentation-style videos, tutorials, explainer videos
- **Cost**: Free tier available, paid plans start at $10/month
- **Link**: https://www.narakeet.com
- **API**: Yes - can be fully automated via API

**Example Markdown format:**
```markdown
# Welcome to CareerPilot

This is your AI co-pilot for winning career moments.

[Show image: dashboard.png]

You can upload your career context and generate personalized materials.
```

### ✅ **Vidon.ai** (AI-Powered)
- **What it does**: AI converts Markdown to video with images, colors, animations
- **How it works**: Submit Markdown → Get video via API
- **Best for**: Marketing videos, product demos
- **Cost**: API-based pricing
- **Link**: https://api.vidon.ai
- **API**: Yes - fully automated

### ✅ **HeyGen** (AI Avatars)
- **What it does**: Creates videos with AI avatars from Markdown
- **How it works**: Markdown → AI avatar narrates → Video generated
- **Best for**: Professional presentations with human-like avatars
- **Cost**: Paid plans available
- **Link**: https://www.heygen.com
- **API**: Yes

### ⚠️ **Limitation**: 
These tools create **presentation-style videos** (slides, images, voiceover), NOT actual screen recordings of your web app.

## For Actual Screen Recordings (Your App)

Unfortunately, **no tool exists** that can automatically:
1. Read your markdown files
2. Navigate your actual web application
3. Record screen interactions
4. Create a video

**Why?** Because screen recording requires:
- Your app to be running
- Actual browser interactions
- Real-time recording
